# Link Card Hub

Create a landing page where when the admin creates a new item in the database, it creates a new card with the given title and subtitle; on click, it goes to the given slug, which redirects to the given link. For example, I can click on a card, which takes me to /hiring, which redirects me to a Google Form link saved in the database. The cards are generated dynamically based on the database items.
